# Import templates

| File | Admin place | Notes |
|---|---|---|
| 1-articles-template.md | Sections, Home, Latest news, Import | Title, Subtitle, Date, Category, Image, Excerpt. Pictures by file name (pick them with the .md, or put all in a .zip). |
| 2-slides-template.md / .csv | Sections, Home, Slider, Import slides | Title, Subtitle, Tag, Image. The CSV also opens in Excel. |
| 3-service-pages-template.md | Sections, a service page (Patents, Trademarks, Translation), Page content, Import | `Service:` and `Language:` lines; text before the first `##` is the introduction, each `##` is a card. |
| 4-services-section-template.md | Sections, Home, Services, Import services | Brief, Icon, Page file, Hidden; pop-up text, then `## Page content` for the dedicated page. A title matching no service adds a new one. |

Word (.docx) works the same way as Markdown: Heading 1 for the title, then the `Label: value` lines, then the text.
